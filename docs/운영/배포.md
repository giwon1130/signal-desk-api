# 배포 (백엔드 SoT)

## 2026-10-24 — 서비스 실행 중지

공개 서비스는 종료 상태야. 2026-10-28 GitHub README·소개에도 종료일을 표시하고, 10분 주기로 운영 API를 호출하던 `keep-alive` GitHub Actions를 제거했어. 앱 저장소의 GitHub Pages는 정적 종료 안내만 게시해.

- 사용자 요청으로 Railway `signal-desk-api`와 같은 프로젝트의 `Postgres` 실행을 중지했어. 실행 중인 배포가 없는 상태를 확인했으며 DB 볼륨·데이터는 보존했어.
- API의 `giwon1130/signal-desk-api` GitHub 소스 연결을 해제했어. 현재 `main` 푸시로 운영 서비스가 켜지지 않아. 사용자가 재개를 요청하기 전에는 재배포·소스 연결 복원·DB 재시작을 하지 않아.
- DB 실제 역할 비밀번호와 DB/앱의 연결 설정, JWT 설정을 갱신했어. 재개할 때 과거 배포의 환경변수로 되돌리지 않아. 최신 Railway 설정을 원본으로 사용해.
- 재개 순서는 보존 볼륨 확인 → 최신 설정으로 DB 기동 → 앱 소스 연결/배포 → `/health`의 JDBC·DB 정상 확인이야. 외부 API 인증정보 상태도 발급처에서 다시 확인해야 해.
- 아래 셋업·일상 배포는 일반 절차이며 현재 중지 상태보다 우선하지 않아.

> **누가 봄**: 운영자
> **언제 봄**: 첫 배포 / 환경 추가 / 문제 발생

## 트러블슈팅

(stub)
| 증상 | 원인 | 해결 |
|------|------|------|
| 시작 실패 (OOM) | heap 부족 | `MaxRAMPercentage` 조정 또는 plan 업 |
| `/auth/*` 404 | file mode | `SIGNAL_DESK_STORE_MODE=jdbc` |
| DB connect fail | Postgres 어태치 안 됨 | Railway 어태치 확인 |
| CORS 403 | env 누락 | `SIGNAL_DESK_CORS_ALLOWED_ORIGINS` 추가 |
| JWT secret 더미 경고 | env 미설정 | `openssl rand -base64 48` 으로 새 값 |
| 외부 API timeout 폭증 | 외부 장애 | fallback 동작. 로그 확인 |
